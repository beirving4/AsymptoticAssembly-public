# Thesis pre-release status

This repository is a citable public checkpoint prepared for the associated
thesis deposit. It separates the portable scientific package from private
research infrastructure and cluster-specific post-processing code.

The `v0.1.0a0` release is intentionally a pre-release. Focused scientific
regression suites used during the publication cleanup pass locally. The
following release-hardening work remains in progress:

- complete clean-environment and supported-version test runs;
- installed-wheel and source-distribution validation on the cluster;
- large-scale merger-tree and high-particle-count performance checks;
- completion of the remaining public workflow extraction;
- final API, documentation, and citation refinement.

These limitations do not change the immutable contents of this tagged
checkpoint. Future improvements will be released under new version tags.

The archived release DOI is `10.5281/zenodo.22136688`.
